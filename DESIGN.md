# Bulls and Cows — DESIGN

## 1. Структуры данных и алгоритмы

**Состояние игры** (`src/state.ts`) — неизменяемый объект: настройки, секрет, история, статус, время начала и конца. Объект удобен, потому что у состояния есть именованные поля. Каждая попытка создаёт новое состояние через `{ ...state }`, старое не меняется.

**История попыток** — массив записей `{ guess, bulls, cows }`. Массив выбран, потому что важен порядок попыток, а новые записи только добавляются в конец: `[...history, entry]`.

**Секрет** — строка, а не число, чтобы не терялся ведущий ноль (`0123`).

**`evaluateGuess`** (`src/evaluate.ts`):

1. bulls — `filter` оставляет цифры, которые совпадают с секретом на той же позиции.
2. matches — `filter` оставляет цифры, которые вообще есть в секрете.
3. cows = matches − bulls.

**`countPossibleSecrets`** (`src/count.ts`) — рекурсия:

- `count(0, base) = 1`;
- `count(length, base) = base × count(length − 1, base − 1)`.

Например, `count(4, 10) = 10 × 9 × 8 × 7 = 5040`. Результаты сохраняются в кэш (`Map`), поэтому повторный вызов не пересчитывается.

## 2. Сложность

`n` — длина секрета, `b` — система счисления.

- **`generateSecret` — O(n · b).** `n` шагов, на каждом `filter` проходит по оставшимся цифрам (не больше `b`).
- **`evaluateGuess` — O(n).** Два прохода `filter` по `n` цифрам, поиск цифры в `Set` — O(1).
- **`isValidGuess` — O(n).** Каждый из `n` символов проверяется один раз, уникальность — через `Set`.
- **`countPossibleSecrets` — O(n) при первом вызове, O(1) при повторном.** `n` рекурсивных вызовов, потом результат берётся из кэша.

## 3. Принципы чистого кода

- **Понятные имена** — `isValidGuess` в `src/validation.ts`: условия названы `hasCorrectLength`, `hasOnlyValidDigits`, `hasNoRepeats`.
- **Одна ответственность** — каждый файл делает одно: `evaluate.ts` сравнивает, `generate.ts` генерирует, `storage.ts` работает с `localStorage`, `main.ts` отвечает за UI.
- **DRY** — `createDigitValidator` (`src/digits.ts`) используется и в `isValidGuess`, и при фильтрации ввода в `main.ts`.
- **Без магических значений** — константы `ALL_DIGITS` (`digits.ts`), `MAX_RECORDS` (`records.ts`), `STORAGE_KEY` (`storage.ts`).
- **Чистые функции** — `generateSecret` и `makeGuess` получают `random` и `now` параметрами, а не вызывают `Math.random()` и `Date.now()` внутри.
